# Workflows page

The five things a project can do, and the list of what it has done already.

User: authenticated

## See what the project can do

Precondition:

1. Inside my project

Steps:

1. Open the Workflows page

Expected:

- "Build" is offered
- "Simulate" is offered
- "Process data" is offered
- "Optimize" is offered
- "Validate" is offered

## Build offers the models it can make

Precondition:

1. On the Workflows page

Steps:

1. Choose "Build"

Expected:

- "Ion channel" can be built
- "Single neuron" can be built
- "Electron microscopy circuit" can be built

## Simulate offers the models it can run

Precondition:

1. On the Workflows page

Steps:

1. Choose "Simulate"

Expected:

- "Single neuron" can be simulated
- "Synaptome" can be simulated

## What the project has done already is listed underneath

Precondition:

1. On the Workflows page

Steps:

1. Go to the list of activities

Expected:

- The activities are listed for one category and one type at a time
- The category chosen is "Build"
- The columns are "Name", "Category", "Type", "Date", "Created by", "Status" and "Actions"
